UNA CONFIGURACIÓN INICIAL. DESPUÉS, CONVERSÁ.

Conectá tu asistente.

MCP es la conexión que permite que una IA use herramientas. Este servidor corre en tu computadora y usa tu sesión de ARCA.

Versión MCP: 1.1.1 · Instalación con npm

Usá el paquete publicado con npx. setup prepara el navegador por vos. No necesitás descargar el código ni compilar el proyecto.

1

Prepará tu computadora

Instalá Node.js 22.13 o superior de la rama 22.x (también se admiten 20.17+ de la rama 20.x y 23.5+). Node.js incluye npm y npx. Abrí Terminal en macOS o PowerShell en Windows y ejecutá estas líneas, una por una.

npx arca-siradig@1.1.1 setup
npx arca-siradig@1.1.1 login

setup instala el navegador compatible con el paquete. También podés ejecutar login directamente: si falta Chromium, te ofrece instalarlo antes de pedir credenciales. Si elegís instalarlo, el login continúa al terminar.

El último comando te pide CUIT/CUIL y clave fiscal en la terminal. Ingresalos ahí: no pegues tu clave en el chat. Si la sesión vence, ejecutá ese comando de nuevo.

2

Elegí dónde usarlo

En Claude Desktop, abrí Settings → Developer → Edit Config. Agregá esta entrada a mcpServers; si ya tenés otros servidores, conservá sus entradas.

{
  "mcpServers": {
    "arca-siradig": {
      "command": "npx",
      "args": [
        "-y", "arca-siradig@1.1.1",
        "mcp", "--allow-writes"
      ]
    }
  }
}

Si Claude no encuentra npx, reemplazá "npx" por su ruta absoluta. Buscala con command -v npx en macOS o where.exe npx.cmd en Windows. En Windows, escribí las rutas del JSON con barras / o barras invertidas dobles \\.

Guardá el archivo y reiniciá Claude Desktop. Verificá que aparezca arca-siradig entre las herramientas disponibles.

Guía oficial de configuración local ↗
ChatGPT web: conexión directa todavía no disponible

Los conectores web necesitan un MCP remoto accesible por HTTP. Este proyecto ofrece un proceso local por stdio; una URL de GitHub Pages no lo convierte en un servidor MCP.

Con OpenAI, podés usar Codex local

Si tenés Codex CLI, registrá el servidor con este comando:

codex mcp add arca-siradig -- npx -y arca-siradig@1.1.1 mcp --allow-writes

Codex usa esta conexión local. La disponibilidad y el acceso a Codex dependen de tu cuenta.

Cómo funcionan los MCP remotos en ChatGPT ↗

Elegí el alcance: estos ejemplos incluyen --allow-writes para permitir cargas en el borrador. Quitalo para usar solo consultas y descargar el PDF. Las aprobaciones de cada operación dependen de tu cliente de IA.

TUS DATOS, CON CONTEXTO

Vos tenés la última palabra.

La clave fiscal se ingresa en la terminal y no se guarda. La sesión se conserva localmente con permisos privados. Los datos fiscales que consultás y los adjuntos que compartís pueden ser visibles para tu asistente y su proveedor de IA.

Revisá los datos antes de cargar y consultá el borrador después. La IA puede interpretar mal un comprobante. El proyecto no calcula topes fiscales ni reemplaza el asesoramiento contable.

ANTES DE EMPEZAR

Algunas respuestas útiles.

¿Esta página se conecta a mi cuenta de ARCA?

No. Es una guía. La conexión se ejecuta en tu computadora mediante el CLI y el MCP; esta landing no recibe credenciales ni datos fiscales.

¿Puedo cargar cualquier parte del formulario?

Las herramientas de escritura actuales agregan detalles mensuales y comprobantes en deducciones compatibles, y eliminan comprobantes de gastos médicos. No cubren todas las ediciones del portal. Consultá la guía MCP para conocer los campos y límites.

¿La IA envía el formulario por mí?

El MCP no tiene una herramienta de envío. Cuando termines de revisar, podés enviar desde el CLI con npx arca-siradig@1.1.1 form submit --period 2026. El comando muestra el resumen y pide confirmación explícita.

¿Qué hago si una carga falla?

Consultá primero las deducciones para verificar si se guardó. No repitas automáticamente la carga: un error puede dejar el resultado sin confirmar aunque el cambio se haya realizado.

¿Tengo que instalar algo cada vez?

La instalación y la configuración del asistente se hacen una vez. Si ARCA vence tu sesión, volvé a ejecutar el comando de login. Para actualizar el paquete, usá la nueva versión y ejecutá setup; después reiniciá la conexión MCP.
